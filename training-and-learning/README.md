# Technical Training & Learning Session Summarization

> **Domain:** 4. Content, Document & Learning Intelligence | **Parent Catalog:** [`../CATALOG.md`](../CATALOG.md)

Prompts designed for software engineers and technical educators to distill recorded training classes, workshops, and educational video transcripts into structured study guides, code demo summaries, and hands-on action items.
